ISOLATED SANDBOX
🛡️
Isolated Process Execution & AST Security Screening

Untrusted user code is never executed directly inside the main web server process. Prior to execution, an AST security visitor scans for forbidden system calls (such as os.system, subprocess, socket, or arbitrary eval). Permitted scripts run in a dedicated temporary subprocess with a strict 3.5-second timeout.
