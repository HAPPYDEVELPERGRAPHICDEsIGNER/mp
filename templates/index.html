Automated Testing

Auto-synthesize unit tests with Python AST and execute them safely inside an isolated child process.

ISOLATED SANDBOX
🛡️
Isolated Process Execution & AST Security Screening

Untrusted user code is never executed directly inside the main web server process. Prior to execution, an AST security visitor scans for forbidden system calls (such as os.system, subprocess, socket, or arbitrary eval). Permitted scripts run in a dedicated temporary subprocess with a strict 3.5-second timeout.

    🛡️ Execution Safeguards & Sandbox Disclaimer
    
            
    
              
    Educational Process Isolation Notice:
    
              
    The automated testing engine executes code in a dedicated local child process with timeouts (5.0s) and static AST security auditing (blocking system module imports such as os, sys, and subprocess). This provides local process isolation for educational development, not a hypervisor virtual machine or military-grade hardware sandbox. Do not run untrusted or adversarial payloads.
